# 精选题目索引

收录需要周期回顾的重要题目。只有在明确表达"精选第 X 题 / 加入精选 / 收藏这道题"等同等意图时才执行精选；每日任务不自动精选。

本索引是精选题目及其标签的**唯一登记处**：精选题目行只写在本文件，根目录 `README.md` 只登记每日训练记录，不登记精选题目行；精选题"是否精选"字段仍同步反映在根目录 `题目索引.md`。

**精选流程**：按题目 ID 找到原始训练文件 → 将完整题目、答案、追问、误区、代码与延伸资料写入独立文件 → 记录原始文件相对路径、来源日期、题目 ID 与题型 → 更新本索引 → 将根目录 `题目索引.md` 中该题"是否精选"更新为"是"。同一题目不重复创建，只更新现有文件与索引；不修改原始题目的核心内容。

## 维护规则

1. 以题目 ID 为幂等键，同一题目不得重复创建精选文件。
2. 更新精选文件时保留其中的复习记录与人工批注。
3. 精选状态同时反映在根目录 `题目索引.md` 的"是否精选"字段，两处需保持一致。
4. 不修改原始训练文件中的题目核心内容。
