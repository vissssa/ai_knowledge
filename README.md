## 内容说明

- **题库配置.md**：定义每日题目结构（非 Agent 基础 2、Agent 基础 2、Agent 场景 1、非 Agent 场景 1、LeetCode 1）和启用的题库类型。每日出题只读取、不修改本文件；每周维护任务可审慎调整。
- **题目索引.md**：只保留运行日向前 3 个自然月（含运行日）的题目明细；旧训练文件仍保留，可按需查阅。
- **精选/**：精选题目及其索引（`精选/README.md`）的唯一维护位置；精选题以独立文件承载原题内容与复习记录，索引表登记来源、标签与复习节奏。本页只做目录级说明，不登记任何精选题目行。
- **每月目录**：每份训练记录含当日学习主题、题型分布、题目与解析，frontmatter 标注日期、题量、LeetCode 编号与标签。

## 使用约定

- 出题以 `题库配置.md` 为准，不自动改配置。
- 训练记录按 `YYYY-MM/YYYY-MM-DD-AI-Agent-面试训练.md` 命名归档。
- 新增训练记录后，在本页导航表追加一行（超链接 + 标签），并按题目 ID 幂等更新滚动题目索引。精选题目及其索引的更新只写在 `精选/` 目录内（`精选/README.md`），不在本页追加行。旧训练文件和本页导航不随索引窗口清理。
