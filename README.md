# AI Agent 面试训练知识库

AI Agent 方向的面试训练题库与每日训练记录。题库配置为唯一来源，每日据此出题，每周维护更新。

## 目录结构

```
.
├── 题库配置.md        # 题库类型唯一来源：题型分布、启用中的基础题类型
└── 2026-10/           # 按月归档的每日训练记录
    └── 2026-10-10-AI-Agent-面试训练.md
```

## 内容说明

- **题库配置.md**：定义每日题目结构（基础定义题 5、真实研发场景题 2、LeetCode 1）和启用中的基础题类型。每日出题只读取、不修改本文件；每周维护任务可按技术趋势更新。
- **每月目录**：每份训练记录含当日学习主题、题型分布、题目与解析，frontmatter 标注日期、题量、LeetCode 编号与标签。

## 使用约定

- 出题以 `题库配置.md` 为准，不自动改配置。
- 训练记录按 `YYYY-MM/YYYY-MM-DD-AI-Agent-面试训练.md` 命名归档。
